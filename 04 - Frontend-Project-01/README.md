# Frontend Project 01

## About the Project

This project is my first frontend website created using HTML5 and CSS3. It is built to practice and apply the core concepts of frontend development by combining them into a complete, modern, and well-structured website. Instead of learning HTML and CSS topics separately, this project focuses on using them together in a real-world development workflow, helping me gain practical experience in structuring webpages and styling them with clean, organized code.
